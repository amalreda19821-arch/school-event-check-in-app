# School Event Check-in App

A beginner Python program that simulates checking in students for a school event.

## How it works

The program:

- Displays a welcome message.
- Collects the name and grade of 4 students.
- Formats each student's name.
- Generates a student ID using part of the student's name and grade.
- Assigns each student to a Junior or Senior Group based on their grade.
- Displays a completion message after checking in all students.
